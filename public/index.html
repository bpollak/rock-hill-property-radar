Connect OneHome property links

Paste the full URL from your current OneHome search or property page. The dashboard keeps its query parameters only in memory and shares them with other open Property Radar tabs in the same browser. A private connection link can supply the same URL in its fragment; the dashboard removes that fragment from the address bar immediately after loading it.

Nothing is saved to the public dataset or browser storage.
